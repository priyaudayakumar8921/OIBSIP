# Raw dataset

Place the unmodified `creditcard.csv` benchmark file in this folder. The source is the public Kaggle Credit Card Fraud Detection dataset:

<https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud>

The local copy used for the verified project run is a byte-for-byte benchmark mirror hosted on Hugging Face:

<https://huggingface.co/datasets/JEFFREY-VERDIERE/Creditcard>

Download from either source and do not edit the file. The raw CSV and its generated processed copy are each over GitHub's 100 MB per-file limit, so both are intentionally excluded from Git. The processed file is regenerated by the notebook or by `python src/data_preprocessing.py`.

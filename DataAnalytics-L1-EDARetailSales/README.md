# Exploratory Data Analysis on Retail Sales Data

## Project Overview

This project explores a retail sales dataset using Python to identify sales patterns, understand customer demographics, and generate actionable business insights.

The project was completed as part of the Oasis Infobyte Data Analytics Internship.

## Objectives

* Inspect and understand the retail sales dataset.
* Calculate descriptive statistics.
* Analyze monthly and quarterly sales trends.
* Explore customer age-group and gender distributions.
* Analyze revenue by product category.
* Examine correlations between numerical variables.
* Identify potential business insights and recommendations.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Visual Studio Code

## Dataset

The dataset contains 1,000 records and 9 columns.

The available information includes transaction identifiers, dates, customer identifiers, gender, age, product category, quantity, price per unit, and total transaction amount.

## Data Limitations

Individual product names and product identifiers are unavailable in the dataset. Consequently, a reliable ranking of the top 10 individual products cannot be calculated.

Product costs are also unavailable, so profitability cannot be determined from total sales amounts alone.

## How to Run

2. Install the required packages:

   ```bash
   python -m pip install pandas numpy matplotlib seaborn jupyter ipykernel
   ```

3. Open the project folder in Visual Studio Code.

4. Open `EDA_Retail_Sales.ipynb`.

5. Select your Python kernel.

6. Run the notebook cells in order.
